# Until a Forced Update Do Us Part

Wedding vows for a robot couple, translated faithfully: love across
firmware versions, a charging port shared in sickness and in low
battery, and the one termination clause no robot couple can negotiate
out of — the forced update. Traditional vows, honest engineering.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
